## 协助 GitHub 推送
- 问题：用户截图显示 `git push -u origin main` 失败，报错 `Failed to connect to github.com:443 over proxy 127.0.0.1`。
- 诊断：git 代理实际配置为 `127.0.0.1:7897`（端口正确且开放），curl 能建立 CONNECT 隧道，但 git push 报 `TLS connect error: unexpected eof while reading` → HTTPS 经代理后 TLS 握手被截断，不是端口问题。
- 验证 SSH：`ssh -T git@github.com` 通且已认证为 `wufan0312`。
- 解决：`git remote set-url origin git@github.com:wufan0312/resume-screening.git` 后 `git push -u origin main` 成功，`main -> main`。
